## 老师提醒的坑

标注说明：`【画面】`= 屏幕上直接可见；`【台词】`= 他嘴上说的（错字已按对照表修正），仅作补充。

1. **`System Core → SYS → Debug` 必须选 `Serial Wire`，不能留 `No Debug`** —— 本段最值钱的一处，因为他**演给你看了**。
   - 【画面】`Serial Wire` 时右侧引脚图 `PA13`/`PA14` 变绿，冒出 `SYS_JTMS-SWDIO` / `SYS_JTCK-SWCLK`；他一改回 `No Debug`，这两个绿色标注**立刻消失**，再改回 `Serial Wire` 又回来（06:54 设成 Serial Wire → 07:06 改回 No Debug 给你看区别 → 07:18 又改回 Serial Wire）。
   - 【台词】"如果你这个地方选 No Debug……会导致你的芯片程序只能下载一次，第二次下不进去了，这个时候你需要通过**串口烧录**的方式给它重新刷写一遍。"

2. **`RCC → High Speed Clock (HSE)` 要选 `Crystal/Ceramic Resonator`**（不是 `Disable`）。
   - 【画面】一选上，右侧 `PD0`/`PD1` 立刻变绿并标成 `RCC_OSC_IN` / `RCC_OSC_OUT`；`GPIO Settings` 子页签同时冒出来。这就是"外设占用了哪两个引脚"的可视化。
   - 【台词】"选择我们的这个晶振时钟，就是 `Crystal / Ceramic Resonator`……底下这些参数都是默认的，不用改。"

3. **`Timebase Source` 保持默认 `SysTick` 就行**（不跑 FreeRTOS 的普通工程）。
   - 【画面】全程 `SysTick` 没被动过。
   - 【台词】"不涉及到 FreeRTOS 的情况下，一般的工程就直接使用 SysTick 就 OK，这个是我们的**系统滴答时钟**……一般情况下用 SysTick 是够了，也不会存在什么问题。"

4. **时钟树看着吓人，"大家不要慌"**。
   - 【画面】他一进 `Clock Configuration`，`SYSCLK`/`HCLK` 本来就只有 **8 MHz**（`System Clock Mux`、`AHB Prescaler=/1` 全是默认，走哪个时钟源本节不判定），整段**一个大参数都没改**，只是顺着左边 input → 分频器 → 各总线讲一遍。
   - 【台词】"大家看到这样一框图看起来非常复杂是吗？大家不要慌……其实它结构也并不是那么的复杂。" → **学生最容易被这张图劝退，实际这段是纯讲解**。

5. **不启用 LSE 时，时钟树里 LSE 输入是灰色的（= 不可用）**。
   - 【画面】09:00 那一格，`Input frequency 32.768 / 0-1000 KHz` 在时钟树最左上，整块是**灰色**。
   - 【画面】09:18 他回 RCC 把 `LSE` 改成 `Crystal/Ceramic Resonator`，`PC14`/`PC15` 变绿标 `RCC_OSC32_IN`/`RCC_OSC32_OUT`；09:24 之后再回时钟树，LSE 那块又变回灰色（说明他又关掉了）。
   - 【台词】"这里它是灰色，因为我们刚才并没有在 RCC 这里去开我们这个低速时钟，所以说这里是灰色，其实不可用的……那咱们今天用不到这个低速时钟，所以先把它关掉。"

6. **HSE 输入频率 8 MHz 是"F103 最小系统板常见值"，换板子必须去查原理图**。
   - 【画面】时钟树 `Input frequency 8 / 4-16 MHz`，这个 8 全程没改；`4-16 MHz` 是他给的范围提示。
   - 【台词】"这给的范围是 4 到 16 兆赫兹……最常见的 STM32F103C8T6 核心板上的那个晶振一般都是 8 兆赫兹的，所以这个不用改了。当然如果你用到一些其他开发板，你可能需要去查一下那个硬件电路，以防止这里晶振频率变了。"

7. **外设（`Connectivity`/`Timers`/`Analog`）可以先一个都不配**。
   - 【画面】他先后把 `Connectivity`（`CAN`/`I2C1`/`I2C2`/`SPI1`/`SPI2`/`USART1`/`USART2`/`USART3`/`USB`）、`Timers`（`RTC`/`TIM1`~`TIM4`）、`Analog`（`ADC1`/`ADC2`）展开看了一下，只点开 `TIM1` 瞄了一眼——**所有下拉全是 `Disable`**，一个都没配就继续往下走了。
   - 【台词】"外设是你的可选项……咱们今天就不太说太多。"

## 操作顺序（本段实际按这个顺序走）

```
① 起始页 New Project → ACCESS TO MCU SELECTOR 建好工程（05:00–05:02）
② Pinout & Configuration 页
   → 左栏 System Core ▸ RCC
③ RCC：High Speed Clock (HSE) = Crystal/Ceramic Resonator   ← 本段唯一真正改的配置之一
   （LSE 保持 Disable；参数全默认；Master Clock Output 不勾）
④ 左栏 System Core ▸ SYS
⑤ SYS：Debug = Serial Wire（中途改回 No Debug 演示坑，再改回 Serial Wire）
   SYS：Timebase Source = SysTick（默认，不改）
   System Wake-Up 不勾
⑥ （可选，本段没配）外设：Connectivity / Timers / Analog —— 全部保持 Disable
⑦ 顶部页签 Clock Configuration
   → 只讲解 + 放大 + 滚动，不改参数（SYSCLK 仍 8 MHz）
   → 中途回 RCC 把 LSE 打开看一眼，随即关掉
⑧ 本段结束时仍停在 Clock Configuration 的放大视图
   （Project Manager / GENERATE CODE 属于后面的段落，本段未进入）
```

一句话记忆：**选芯片 → 建工程 → RCC 开 HSE 晶振 → SYS 勾 Serial Wire + Timebase=SysTick → 时钟树查看 → （后面才进 Project Manager / 生成代码）**。
