## 操作顺序（他实际点的次序，画面为准）

0. **前置（10:00 之前已完成，只在本段被回看）**：Pinout & Configuration → System Core → **RCC**：**HSE = Crystal/Ceramic Resonator**、**LSE = Disable**、Master Clock Output 不勾
1. 点 **Clock Configuration** 标签
2. **PLL Source Mux**：从 **HSI** 点成 **HSE**（HSE 前级分频保持 **/1**，不选 /2）
3. **\*PLLMul**：先停 **X 2**（给人看 8×2=16），再改 **X 9**（8×9=72）
4. **System Clock Mux**：选第 3 个 **PLLCLK** → SYSCLK 立刻 8→72
5. **AHB Prescaler** 不动（**/1**，HCLK=72 ≤ 72 max）
6. **APB1 Prescaler 改成 /2**（PCLK1=36 ≤ 36 max）← **本段结束时他还没改，画面停在 /1 报错**
7. APB2 Prescaler **/1**（72）、ADC Prescaler **/2**（36）不用动
8. 中途插播：Pinout & Configuration → Connectivity → **USB**（确认 Device (FS) 未勾），回来解释 USB 分频器为何是灰的
