### 2. Clock Configuration 页（15:00–15:54，全程只读不改）

工具栏里有 `Resolve Clock Issues` 按钮，本段**一直是灰的**。

左列 `Input frequency`：

| 项 | 画面值 | 备注 |
|---|---|---|
| LSE | `32.768`，下方 `0-1000 KHz` | **整块是灰的**（不可用） |
| `LSI RC` | `40`，下方 `40 KHz` | 蓝色（可用） |
| `HSI RC` | `8`，下方 `8 MHz` | 蓝色 |
| `HSE` 的 `Input frequency` | `8`，下方 `4-16 MHz` | 蓝色，有双向箭头指进 HSE |

中右段：

- `PLL Source Mux`：`HSI`（带一个灰的 `/2`）/ `HSE`（**选中**）。
- `PLLMul`：输入 `8` × **`9`** → 输出；PLL 方块悬停提示 `VCOInput`。
- `USB Prescaler`：`/1`；`To USB (MHz)` = **`72`**。
- `System Clock Mux`：三选 `HSI` / `HSE` / **`PLLCLK`（选中）**；旁边有 **`Enable CSS`** 蓝字按钮。
- `SYSCLK (MHz)` = **`72`**。

AHB / APB 段：

- `AHB Prescaler` = **`/1`** → `HCLK (MHz)` = **`72`**，下方蓝字 `72 MHz max`。
- HCLK 扇出三路：`72`（`HCLK to AHB bus, core, memory and DMA (MHz)`）、`/1` → `72`（`To Cortex System timer (MHz)`）、`72`（`FCLK (MHz)`）。
- `APB1 Prescaler` = **`/2`** → `PCLK1` 蓝字 `36 MHz max` → **`36`**（`APB1 peripheral clocks (MHz)`）；`X 2` → **`72`**（`APB1 Timer clocks (MHz)`）。
- `APB2 Prescaler` = **`/1`** → `PCLK2` 蓝字 `72 MHz max` → **`72`**（`APB2 peripheral clocks (MHz)`）；`X 1` → **`72`**（`APB2 timer clocks (MHz)`）。
- `ADC Prescaler` = **`/2`** → `To ADC1,2` = **`36`**。
- 左下 `MCO source Mux`：`PLLCLK` / `HSI` / `HSE` + 一个 `/2`，输出 `72`。

## 老师提醒的坑

> 下面每一条都**先给画面依据**（本段真实看到的），再补台词说明。台词只作解释，不单独作为事实来源。

**1）点灯别选 PC14 / PC15，它们被外部低速晶振占着。**
- 画面依据：点开 PC14 的下拉，选项里第一顺位就是 `RCC_OSC32_IN`；PC13 的菜单里对应位置是 `RTC_OUT` / `RTC_TAMPER`。也就是说 PC14/PC15 这对外部低速晶振脚有专门的复用项。
- 台词（16:18–16:30）：要开外部低速晶振就会占用 PC14、PC15，所以这里挑 PC13。
- 学生踩法：照着"点灯"教程随手选 PC14/PC15，后面一开 LSE 就冲突。

**2）`GPIO_Input` 和 `GPIO_Output` 在同一个菜单里挨着，选错就是灯不亮。**
- 画面依据：菜单里 `GPIO_Input` 紧挨在 `GPIO_Output` 上面，他只点了 `GPIO_Output`。
- 学生踩法：以为"配了引脚"就行，实际选成 Input，代码里怎么翻转都不亮。

**3）输出模式默认是 `Output Push Pull`，另一个 `Output Open Drain` 不能拿来点灯。**
- 画面依据：18:34 他把它切成 `Output Open Drain` 演示，18:48 又切回 `Output Push Pull`；最终工程里留的是 `Output Push Pull`。
- 台词（17:33–18:36）：推挽有驱动能力，能强制拉高/拉低；开漏没有驱动能力，要变高必须外部加上拉。还提到 STM32 的 GPIO 电平标准是 3.3 V，用推挽去拉 5 V 拉不上去、甚至可能弄坏。
- 学生踩法：选成开漏后示波器/万用表上永远是低，以为芯片坏了。

**4）`GPIO Pull-up/Pull-down` 默认是"都不上拉下拉"，引脚会浮空。**
- 画面依据：默认值 `No pull-up and no pull-down`，他在 19:36 左右改成 `Pull-down` 才继续。
- 台词（18:51–19:41）：浮空时输入电平是不稳定状态，芯片内部有两个可编程电阻可以拉高/拉低；这里选下拉。
- 学生踩法：不配上下拉，按键/复位脚读数乱跳。

**5）判"时钟配好了"要看颜色和按钮，不是背数字。**
- 画面依据：15:00–15:54 整棵树都是蓝色、没有一个红字，工具栏 `Resolve Clock Issues` 是灰的（不可点）；他一离开这一页就说明认为配完了。
- 台词（15:54–16:00）：这边没有报错，就说明时钟树配置完成、没问题了。
- 学生踩法：只盯着 72/36 几个数，颜色红了（超频）却没注意。

**6）APB1 的 36 MHz 上限是直接写在图上的。**
- 画面依据：`PCLK1` 下面蓝字 `36 MHz max`、`HCLK` 下面 `72 MHz max`、`PCLK2` 下面 `72 MHz max`。
- 学生踩法：把 `APB1 Prescaler` 也设成 `/1`（以为"拉满最快"），72 > 36，树立刻变红。

**7）灰色 = 没开对应功能，所以改不了。**
- 画面依据：`LSE` 整块是灰的（`Input frequency` 显示 32.768 但不可编辑），因为前面没在 RCC 里开 LSE；`USB Prescaler` 同理。
- 学生踩法：第一次进时钟页发现"这一栏怎么点不动"，以为软件坏了。

**8）表格最后一列 `Modified` 能一眼看出哪些脚真的改过。**
- 画面依据：17:06 时是空方框，18:24 起变成已勾选；上方还有 `Show only Modified Pins` 复选框。
- 用途：脚配多了以后只看改过的，避免漏配。
