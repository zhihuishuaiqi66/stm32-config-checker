## 讲师强调的坑（口播要点 + 画面对应）

1. **“我们每打开一个外设，我们都叫什么什么 start”**（11:41）→ 画面：ADC 已有 `HAL_ADC_Start(&hadc1)`，加 DMA 后写成 `HAL_ADC_Start_DMA(...)`；两者并存于 12:00–12:16。
2. **`HAL_ADC_Start` 可以删掉**（12:28 口播：Start_DMA 会把 ADC 和 DMA 一起打开）→ 画面：12:16 还有第 97 行 `HAL_ADC_Start`，12:32 已消失。
3. **`pData` 是“搬到哪”的地址**（12:04–12:11）→ 画面：12:32 悬停说明 `pData = Destination Buffer address`；故第二参写 `&ADC_Value`。
4. **只搬一次 → 第三个参数写 1**（12:23）→ 画面：12:24 `Length` 被选中，12:32 已变成 `1`。
5. **ADC 是 12 位 → 变量用 16 位就够，还能提高 DMA 速度**（12:43–12:50）→ 画面：12:40 `uint32_t ADC_Value` → 12:52 `uint16_t ADC_Value;`。
6. **DMA 选的是“半字”，一次传 16 位，所以变量必须 16 位**（12:53–13:02）→ 画面：12:56 DMA Data Width 两侧 `Half Word`；变量 `uint16_t`。
7. **类型不匹配要强转**（13:02–13:10）→ 画面：12:52 `&ADC_Value` 出现黄色类型波浪线；13:08 写 `(uint32_t)` 漏星号 → 状态栏 `Syntax error`；13:16 补成 `(uint32_t*)`。
8. **用了 DMA 就不用阻塞等待**（12:16）→ 画面：`HAL_ADC_PollForConversion(...)` / `HAL_ADC_GetValue(...)` 两行变灰色 `//`。
9. **ADC 转换完一次会关闭，所以 Start 不能只放在 while 外**（13:15–13:30）→ 画面：13:28 整行选中 → 13:32 移进 `while(1)` 第 105 行。
10. **“可以看到数据是零了”**（13:33）→ 画面：13:36 VOFA+ 整列 `0`、曲线平线。
11. **“打开信号发射器…波形已经出来了”**（13:36–13:38）→ 画面：13:40 正弦波 + 0–3931 的实时数值。
12. **“每搬运一次就重新打开一次不优雅，用 ADC 自动转换”**（14:05）→ 画面：14:08 Start_DMA 被移回初始化区第 98 行；14:12 进 CubeMX，14:16 `Continuous Conversion Mode = Enabled`；14:20 弹窗重新生成代码。
13. **“这样肯定不行”——DMA 长度只有 1，搬一次就不搬了，ADC 却一直在转换**（14:19–14:48）→ 画面：14:24–14:52 代码一直是「98 行只调一次 + while 里只 printf」，没有再进 while 重启。
14. **“得打开 DMA 的循环模式”**（14:56 起）→ 画面：14:56–15:00 只有画图板和代码，**改 Circular 的操作在本段结束前没有出现**（在 15:00 之后）。

## 看不清 / 没拍到

1. **10:00 的 Clock Prescaler 值被面板宽度截断**：只能读到 `Synchronous clock mode divide…`；11:40 / 14:16 同一项读全 = `Synchronous clock mode divided by 4`。
2. **10:00 的 External Trigger 值被截断**：`Regular Conversion launched b…`（按原文照抄，不补全）。
3. **采样时间（Sampling Time）本段一次都没出现**：ADC_Regular_ConversionMode 只展开到 `Rank 1`，下面 Channel / Sampling Time 子项没展开。
4. **没有 ADCCLK 实际频率**：本段从未打开 `Clock Configuration` 页，画面里没有任何 MHz 数字。
5. **14:12 的 DMA Mode 值读不到**：CubeMX 面板被挤窄，只露出 `Mode` 下拉框边框，看不到 `Normal/Circular` 文字。
6. **14:56–15:00 第 98 行第三个参数被裁**：右侧被画图窗口占住，`HAL_ADC_Start_DMA(&hadc1, (uint32_t*)&A…` 后面看不到（按 14:08 同一行推断是 `, 1);`，但本段最后这几帧确实是裁断的）。
7. **Continuous Conversion 的切换动作没被单独一帧抓到**：11:24 显示 `Enabled`、11:40 已是 `Disabled`、14:16 又是 `Enabled`；只能按前后状态判断，中间那一下点击没有定格画面。
8. **本段完全没有 TIM**：没有 Prescaler / Counter Period / 触发源界面，也没有任何频率换算数字；VOFA+ 只显示 ms 时间轴，没有 Hz。
9. 拼图单格（520×293）里 CubeMX 数值框、代码行、串口数值全部糊成色块，所有数值都是我按同一时间点抽 1920×1080 原帧读出来的；拼图本身可用来确认“这一格是 CubeMX 还是代码还是波形”，读数值不行。
