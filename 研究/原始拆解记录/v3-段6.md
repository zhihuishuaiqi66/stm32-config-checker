## 观察到的现象与数字

### A. VOFA+（串口波形上位机）配置与状态条

- 数据引擎 **FireWater**；数据接口 **串口**；端口号 **COM12（USB-SERIAL CH340, wch.cn）**；波特率 **115200**；数据流控 None；校验位 None；数据位数 **8**；停止位数 **1**；流控信号 DTR / RTS / Break。

### F. 白板示意图（25:36–27:30，讲原理时的画面）

- 内容：**ADC / CPU / DMA / RAM** 四个黑框（红字手写）；紫色粗箭头把它们连起来（ADC↔CPU、ADC↔RAM/DMA 方向成叉状）；一条**红色带刻度的长条**代表数组/缓冲区（满格小方框）；**蓝色粗正弦 + 一排红色圆点**代表采样点；**绿色向下箭头**（刻度尺上方）和**蓝色向上箭头**（刻度尺下方）代表两个指针；手写红字「两条竖线 + 横线 + dt」标注两点间隔（台词读作“DTE”，即 Δt）。
- 画布信息：25:36 为 913×878 像素、163.5%；26:54 放大到 314%；窗口标题「empty.png - 画图」。

### G. 采样率 / 频率（画面与口述分开记）

- **画面**：TIM3 Clock Source = Internal Clock，PSC = **170 - 1**，Counter Period(ARR) = **10 - 1**，TRGO = **Update Event**；ADC1 外部触发源 = **Timer 3 Trigger Out event**，边沿 = rising。
- **口述（ASR，25:09–27:14 一段）**：采样率 100K；一个信号周期约采 100 个点；两个采样点间隔严格相等、完全由定时器决定。
- **推导（画面未直接显示）**：若 TIM3 计数时钟为 170 MHz，则 170 MHz ÷ 170 ÷ 10 = **100 kHz**，与口述 100K 一致；但本段没有打开 Clock Configuration 页，画面未出现 170 MHz 或 ADCCLK 数值，故 170 MHz 属推导。
