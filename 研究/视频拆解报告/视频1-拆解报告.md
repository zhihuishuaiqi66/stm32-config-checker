## 二、完整时钟树（四段拼起来的全貌）

```
                     ┌── HSI RC  8 MHz ──┐  固定 ÷2
   LSI RC 40 kHz ──┐ │                   ├──────────┐
                   │ │  HSE 8 MHz ───────┘          │
                   │ │        └─ ÷1 或 ÷2 ──────────┤   （★ 可选！见 §四.1）
                   │ │                              ↓
                   │ │                    ┌─── PLL 锁相环 ───┐
                   │ │                    │  ×2 ×3 … ×16     │ 本例 ×9
                   │ │                    └──────────────────┘
                   │ │                              ↓
                   │ │                       SYSCLK = 72 MHz
                   │ │                              ↓
                   │ │                    ┌─ AHB 预分频 ─┐  /1
                   │ │                    ↓              ↓
                   │ │              HCLK = 72 MHz     FCLK 72 MHz（HCLK 停仍跑）
                   │ │                    │
                   │ │        ┌───────────┼───────────────┬──────────────┐
                   │ │        ↓           ↓               ↓              ↓
                   │ │   内核/内存/DMA  SysTick        APB1 预分频    APB2 预分频
                   │ │     72 MHz       /1 → 72        /2 → PCLK1 36   /1 → PCLK2 72
                   │ │                  /8 → 9                          │
                   │ │                                    ↓             ↓
                   │ │                              ×2（硬件自动）  ×1（硬件自动）
                   │ │                                    ↓             ↓
                   │ │                          APB1 定时器 72    APB2 定时器 72
                   │ │                                                      ↓
                   │ │                                              ADC 专属预分频
                   │ │                                              /2→36  /4  /6→12  /8
                   │ │
                   │ ├─ ÷128 ─→ HSE_RTC ─┐
                   │ └─ LSE 32.768 kHz ──┼─→ RTC Clock Mux → RTC 40 KHz / IWDG 40 KHz
                   │                     │
                   │        FLITFCLK 8 MHz（恒来自 HSI，不走 HCLK）
                   │
                   └─→ MCO 时钟输出（选一路信号，经 /2 → 36 MHz，从 PA8 输出）
```

## 四、⚠️ 与我的数据/规格书不一致的地方（逐条结论）

### 4.1 【已确认修正】F103 的 HSE 进 PLL 前**有 ÷1 / ÷2 选择器**

| 来源 | 说法 |
|---|---|
| 视频 11:35–11:42（画面 + 字幕） | HSE 输入前有一个**可以选择除以 1 或除以 2** 的分频器 |
| CubeMX 时钟树定义 `db\plugins\clock\STM32F102.xml` | 确实有 `<Element id="HSEDivPLL" type="devisor" refParameter="HSEDivPLL">` |
| **CubeMX CLI 实测** | `HSEDivPLL=1` + `PLLMUL=9` → SYSCLK **72,000,000**；`HSEDivPLL=2` + `PLLMUL=9` → **36,000,000** |

**结论：我原来写的「F1 的 HSE 直接进 PLL、绝对不能除以 2」是错的。**
正确表述：**默认 ÷1（要跑满 72MHz 必须用 ÷1），可选 ÷2**；用 ÷2 时最高只能 ×16 = 64MHz，反而上不了 72。

已修：`data.json` 增加 `hse_pll_div: [1, 2]`、`hsi_pll_div: 2`。

### 4.2 【产品的价值点，不是数据错】F103 的 ADC 上限

| 来源 | 数值 |
|---|---|
| **CubeMX 截图（视频 A/D 段）** | `APB2 72 ÷ ADC Prescaler /2 = 36 To ADC1,2`，**灰色未标红** |
| 我的 data.json | `limits.adc = 14` |
| ST RM0008 | ADCCLK 最大 **14 MHz** |

**结论：CubeMX 在这里不拦。** 36MHz 远超 14MHz 上限，CubeMX 只是灰显、不报红、不阻止生成。
→ **这正好是"我这工具能做、CubeMX 不做"的实证**，可以写进作品帖。

### 4.3 【需修正数据】F103 的 USB 时钟

CubeMX 显示 `USB Prescaler /1 → 72 To USB`。但 F103 的 USB 时钟不是 72MHz：
RM0008 规定 F103 的 USB 时钟 = **PLLCLK ÷ 1.5**，PLL = 72MHz 时 USB = **48MHz**。
所以画面那个「72」标的是 **PLL 输出频率**，不是 USB 实际频率。

- `data.json` 现在 F103 的 `limits.usb = null` → 应改成 **48**，并注明「来源 PLLCLK / 1.5，PLL 必须 72MHz」

### 4.4 【不是冲突】AHB 预分频 /512

画面写「/1 /2 /4 … /256」（省略号），我的数据是 `[1,2,4,…,256,512]`。
RM0008 的 HPRE 支持 /512，**数据是对的**，视频只是没列全（用了省略号）。

### 4.5 【数据缺项】SysTick 分频器 /1 和 /8

画面明确画出，`data.json` 没有这个字段。要加 `systick_div: [1, 8]`。

### 4.6 【新增字段】FCLK / CSS / MCO / FLITFCLK

| 项 | 视频说法 | data.json |
|---|---|---|
| FCLK | 来自 AHB 预分频器，HCLK 停时仍跑 | 无 |
| CSS | 监控 HSE/PLL 后的 HSE，失效切 HSI + 中断 | 无 |
| MCO | 可选时钟源，从 **PA8** 输出，可 ÷1/÷2/÷4 | 无（PA8 的 funcs 里可能有 MCO 信号） |
| FLITFCLK | 恒 8MHz 来自 HSI | 无 |
