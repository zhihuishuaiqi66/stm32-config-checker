## 三、⚠️ 需要修正我之前说法的地方

### 3.1 CubeMX 到底拦不拦？——要分两种

我之前说「CubeMX 不拦超频」，**不准确**。视频画面证据：

| 情况 | CubeMX 行为 | 证据 |
|---|---|---|
| **总线时钟超限**（HCLK/APB1/APB2） | **会标红/品红**，`Clock Configuration` 标签页前出现品红圆点，`Resolve Clock Issues` 按钮从灰变可点 | v2 段3：APB1 /1 时 PCLK1=72 品红 + 老师"红色的就有问题" |
| **外设时钟超限**（ADC） | **不拦，灰色显示** | v1 段A/D：`ADC Prescaler /2 → 36 To ADC1,2`，远超 F103 的 14MHz 上限，无红 |
| **生成代码时** | 超限会报 `IP not ready for code generation: Clock`（我自己实测过） | CubeMX CLI 实测 |

**准确表述**：**CubeMX 管总线频率，不管外设上限；管到"生成不了"为止，不管"跑起来会怎样"。**

→ 我的工具价值点要改口：**不是"CubeMX 不拦"，而是"CubeMX 不拦外设上限、也不告诉你配成这样会出什么现象"**。

### 3.2 CubeMX 确实会标 max，而且建议"拉满"

画面里 PCLK1 下印着 `36 MHz max`、HCLK 下印着 `72 MHz max`、PCLK2 下印着 `72 MHz max`。
**这些提示是有的**，所以"CubeMX 不告诉你上限"这个说法也不成立。

→ 真正缺的是：**它不告诉你"拉满之后你的定时器/PWM/波特率会变成多少"**。

## 四、21 个可复用的坑（按"学生真会犯"排序）

| # | 坑 | 后果（学生看到的现象） |
|---|---|---|
| 1 | SYS 的 Debug 选了 No Debug | 程序只能下载一次，第二次下不进去 |
| 2 | APB1 预分频忘记改，直接"拉满" | 时钟页变红，不知道该除以几 |
| 3 | 工程路径带中文 | Keil 打不开/编译不过 |
| 4 | 点 GENERATE CODE 后窗口变灰 | 以为卡死，强杀进程 |
| 5 | GPIO 输出模式选开漏 | LED 不亮（没有驱动能力） |
| 6 | GPIO 上下拉留默认 | 输入浮空，电平乱跳 |
| 7 | 点灯选了 PC14/PC15 | 和 RCC_OSC32_IN 抢引脚，灯不亮 |
| 8 | 忘了在 RCC 里开 HSE | 时钟树里 PLL 用不了 |
| 9 | HSE 频率没按板子改（默认 8，板子可能 25） | 整个时钟树错 3 倍 |
| 10 | 不知道灰色=未启用 | 一直找"为什么这一行点不动" |
| 11 | 不知道品红=错误 | 带着错误配置去生成 |
| 12 | PWM 频率算错 | 定时器出不来想要的频率 |
| 13 | ADC 时钟超 14MHz | 采样值乱跳，以为是传感器坏 |
| 14 | 时钟没配就开始写代码 | 后面全要返工 |
| 15 | USB 没开就去查 USB 分频器 | 白找 |
| 16 | 只勾了外设没生成代码 | 代码里找不到初始化函数 |
| 17 | 反复点"打开工程" | 开了一堆 Keil 实例 |
| 18 | 选了 from ST Board 而不是 from MCU | 引脚被自动配成官方板的样子 |
| 19 | 没登录 ST 账号 | CubeMX 用不了/包下不了 |
| 20 | 生成时缺固件包 | 不知道要选"现在下载" |
| 21 | SysTick 被 FreeRTOS 抢 | 时序全乱 |

**这 21 条里，有 12 条已经在我原来的自查清单里。** 说明清单方向是对的，但**要按"现象"组织，不是按"配置"组织**。

## 五、这条视频对产品定位的最大启示

视频里学生的完整操作链是：

```
看视频 → 模仿点 → 拉满 → 看到红色 → 除以2 → 消红 → 生成 → 烧进去 → 不跑 → 懵
```

**中间那一步「不跑 → 懵」是整个链条里唯一没人管的环节。**

- CubeMX 管配置合法性（红色消掉 = 合法）
- 视频管操作示范（照做）
- **没人管"我这个配置配出来，实际会是什么现象"**

→ 这就是产品的落点，也是两条视频共同指向的空白。
