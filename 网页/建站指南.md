# Qoder Sites 建站指南

> 目标：把 `规格书/作品规格书-v2.3.md` 变成**评委点开就能玩**的静态网页，发布到 Qoder Sites，拿到公开链接。
>
> 交件要求（天池赛题页原文）：**部署到 Qoder Sites 并开放公开访问** + 在天池论坛发作品帖。

---

## 零、先搞清楚三件事

| 问题 | 答案 |
|---|---|
| 用什么做 | **Qoder 客户端**（v0.3.3 以上），在会话里说「用 /sites 帮我做一个网页」 |
| 要数据库吗 | **不要**。我们是纯前端静态站，免费版就够（免费版只支持静态站） |
| 发布后什么链接 | Qoder 给你一个固定域名，形如 `https://xxx.qoder.zone/` 或 `https://xxx.qoder.website/` |

**关键**：Qoder Sites 是**对话式**建站——你把需求说清楚，它生成、预览、你再改。所以**提示词写得好不好，直接决定成品**。

---

## 一、操作流程（5 步）

### 第 1 步：新建站点

打开 Qoder 客户端 → 新建会话 → 直接输入：

```
/sites 帮我做一个 STM32 配置自查工具网站
```

或者不提 `/sites` 也行，直接描述需求，Qoder 会自动识别。

### 第 2 步：按轮次提需求（**不要一次全塞进去**）

按 `提示词.md` 里的 **第 1 轮 → 第 5 轮** 顺序发，每轮发完先看预览，不对就当场说。

| 轮次 | 做什么 | 大约耗时 |
|---|---|---|
| 第 1 轮 | 骨架 + 首页 + 第 1 屏（时钟台） | 3–8 分钟 |
| 第 2 轮 | 第 2 屏（体检台：17 条规则） | 5–10 分钟 |
| 第 3 轮 | 第 3 屏（导出）+ 学习模式（先猜后揭晓） | 5–10 分钟 |
| 第 4 轮 | 视觉打磨（配色 / 动效 / 手机适配） | 2–5 分钟 |
| 第 5 轮 | 发布 |

### 第 3 步：逐轮验收

每轮发完，用 `提示词.md` 每轮末尾的**验收点**检查。不对就一句话描述现象，让 Qoder 改。

> 新手最容易犯的错：一轮要求太多，AI 做偏了你也不知道从哪问起。**一轮只干一件事。**

### 第 4 步：发布

预览满意后，对 Qoder 说：

```
把这个站点发布上线，设置为公开访问，任何人都能打开
```

它会自动构建 → 生成草稿 → 发布 → 给你一条固定链接。

### 第 5 步：自测链接（**必做**）

| 检查 | 怎么做 |
|---|---|
| 无痕窗口能打开 | 复制链接到**无痕/隐私窗口**，不登录也要能看 |
| 手机上能看 | 用手机浏览器打开同一个链接 |
| 计算对不对 | 按 `验收清单.md` 里的 5 个数逐一核对 |

| 素材 | 怎么用 |
|---|---|
| `提示词.md` | **照着发**，这是主力 |
| `页面文案.md` | 第 2、3 轮要用到的所有文字，直接整段贴进去 |

## 三、这个站必须做到的三件事（做不到就白做）

### 1️⃣ 必须现场算出「定时器实际拿到多少」

这是全站最有价值的一格。学生只知道 PCLK1 = 36MHz，**不知道定时器实际是 72MHz**。

要求页面同时显示：

```
PCLK1          36 MHz      ← 你在 CubeMX 看到的
TIMxCLK        72 MHz      ← 硬件自动 ×2（这才是定时器真正用的）
```

并且加一句说明：**这个 ×2 你在 CubeMX 里改不了，只能算进去。**

> 我们的两块板都实测过：F103 实测 2000ms → 确认 72MHz；F407 实测 2000ms → 确认 84MHz。

### 2️⃣ 必须让用户「先猜，再揭晓」

这是 StudyHack 赛道的关键——**不能只是查表工具，得是能学到东西的东西**。

做法：每条规则卡的答案默认折叠，用户先自己想「会怎样」，点开才看到真实结果。

### 3️⃣ 必须诚实标注证据来源

每条规则卡底部标清楚这条结论是：

- 【实测·自己板子】= 在我们自己的 F103 / F407 上跑过
- 【实测·CLI】= 本机 CubeMX 6.15.0 命令行回读
- 【手册】= ST 参考手册
- 【待核】= 还没验证

**评委最吃这一套。** 而且在"ADC 超限"那条上，我们实测**推翻了自己的说法**——这种诚实比编现象值钱得多。

## 四、常见坑

| 坑 | 现象 | 怎么避免 |
|---|---|---|
| 一轮要求太多 | AI 做到一半跑偏，改不动 | **一轮只做一件事**（见轮次表） |
| 让它「看着办」 | 出来的东西跟你想要的不一样 | 每轮都给**具体的数字和文案**，别让它自由发挥 |
| 忘记说「不要数据库」 | 免费版可能受限 | 提示词第一句就写明「纯前端静态站，不需要数据库」 |
| 发布后没设公开 | 评委打不开 | 发布时明确说「设置为公开访问」 |
| 只在登录状态测 | 评委没登录就看不到 | 用**无痕窗口**验证 |
| 中文乱码 | 编码问题 | 让 Qoder 用 UTF-8；发布后看一眼中文有没有变方块 |
