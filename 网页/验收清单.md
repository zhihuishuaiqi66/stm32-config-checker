## 二、算得对不对（5 个必须对的数）

打开「时钟台」，按下面填，看结果对不对：

### ① F103C8T6 + HSE 8MHz + ÷1 + ×9 + APB1 ÷2

| 项 | 应该是 |
|---|---|
| SYSCLK | **72 MHz** |
| HCLK | **72 MHz** |
| PCLK1 | **36 MHz** |
| PCLK2 | **72 MHz** |
| **TIMxCLK** | **72 MHz** ← 最关键的一格 |
| ADC 时钟（÷6） | **12 MHz** |

### ② F407ZGT6 + HSE 8MHz + PLLM 8 + PLLN 336 + PLLP 2 + PLLQ 7 + APB1 ÷4

| 项 | 应该是 |
|---|---|
| SYSCLK | **168 MHz** |
| PCLK1 | **42 MHz** |
| PCLK2 | **84 MHz** |
| **TIMxCLK（APB1）** | **84 MHz** ← 36→72 那个规则在 F4 上的版本 |
| USB 时钟 | **48 MHz** |

### ③ F411CEU6 + 25MHz + PLLN 200

| 项 | 应该是 |
|---|---|
| SYSCLK | **100 MHz**（上限，正好合规） |
| USB 时钟 | **50 MHz** → 必须标红（USB 要 48） |

### ④ F411CEU6 + 25MHz + PLLN 192

| 项 | 应该是 |
|---|---|
| SYSCLK | **96 MHz** |
| USB 时钟 | **48 MHz** → 绿色，合规 |

### ⑤ 超限必须变红

F103 把 HCLK 拉到 **84MHz**（HSE 8 × 10.5 不行，用 HSE 8 ÷1 ×12 = 96 更直接）：
- SYSCLK **96 MHz** → 必须红，并且提示「上限 72」

> 这 5 组数字全部来自我们本机 CubeMX CLI 回读和上板实测。**任何一项对不上，都说明页面算错了。**

## 八、如果不合格，怎么跟 Qoder 说

| 问题 | 你就这样说 |
|---|---|
| 某个数字错 | 「F103 选 HSE 8MHz、÷1、×9、APB1 ÷2 时，TIMxCLK 显示 xxx，应该是 72MHz」 |
| 卡片数量不对 | 「体检台只有 N 张卡，应该有 17 张」 |
| 答案没折叠 | 「学习模式开着的时候，规则卡的答案应该默认折叠，点了才展开」 |
| 出处没颜色 | 「出处的【实测·自己板子】标签应该是绿色，【待核】是琥珀色」 |
| 超限没变红 | 「F103 把 SYSCLK 配到 96MHz，应该有红色提示说超过 72 上限」 |

**给现象 + 给期望值**，它改得才准。
